# Python Projects

### About

This repository documents my journey of learning Python alongside my Software Engineering degree. 

Rather than focusing only on theory, I will be building projects, completing challenges, researching Python, and improving my code to be clean and efficient. 

### Goals

- Refresh my Python knowledge and fundamentals
- Improve my logical thinking and problem-solving skills
- Become confident writing Python code independently
- Learn to work with files, APIs, and databases
- Develop good programming practices (Testing, Debugging, Clean Code)
- Build complex projects to prove my ability
- Develop skills useful for a future in Software Engineering 

### My Approach

I aim to spend around 30-60 minutes per day on average learning Python where my University workload allows.

I will prioritise practical projects rather than theory. 

For each project I must:

1. Understand the requirements
2. Plan the solution beforehand
3. Break the problem into smaller tasks (Abstraction)
4. Research unfamiliar concepts myself 
5. Implement the solution
6. Test and debug my work
7. Review the project and identify any improvements

I will make sure I know well how my code works rather than simply getting a working result.

### Progress Tracking

Projects will be organised into folders, each progressing from simple Python to more advanced programs.

I will document where I found difficult, and how I can improve along the way.

The goal is consistent progress, not completing everything quickly.
