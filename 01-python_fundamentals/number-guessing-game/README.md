# Number Guessing Game

The task is to build a number guessing game which allows the user to repeatedly guess numbers until they guess the correct randomised number. This is part of learning Python's fundamentals and introduces a few new concepts.

### Added Features

- Generates a random number between 1 and 100
- Ask user to enter a number
- Tell them whether the guess it too high or too low
- Continue until guess is correct
- Counter for number of attempts
- Input validation
- Option to play again after winning

### Requirements

Python3

### How to run this program

1. Clone this repository or download project files
2. Open a terminal in the project directory
3. Run the program using Python

### Concepts to practise

- Random module
- Loops 
- Conditional statements
- Variables
- Input validation
- Functions
