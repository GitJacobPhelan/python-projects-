# Text Analyser

This task is to build a text analyser which allows the user to enter a sentence or paragraph and then analyses it.

### Added Features

- Ask the user to enter some text
- Count the total number of characters
- Count the number of words
- Count the number of sentences
- Display the results
- Count how often each word appears
- Identify the most frequently occurring word 
- Ignore differences between uppercase and lowercase words
